DOBERTO APK

A Web-to-APK platform designed to turn a website URL into a configurable Android application project, with authentication, project history and native Android build tooling.

Product typeWeb-to-APK / Android
Core stackNode.js · Supabase · Kotlin / Android
SourcePrivate
StatusActive development

What it does

  • User registration and sign-in.
  • Website URL onboarding and project creation.
  • App name, package, color, icon, orientation and WebView configuration.
  • Project and build history.

Product architecture

The frontend is prepared around authenticated user projects, while APK/AAB generation is designed to run through an isolated Android worker using the Android SDK, JDK and Gradle rather than compiling arbitrary builds in the web process.

Android layer

The repository includes native Android work alongside a reusable Android template, with update handling, app branding, WebView configuration and build-oriented project code.

Data & security

Supabase is used for authentication and project data, with row-level access rules intended to isolate each user's profiles, projects and builds.
